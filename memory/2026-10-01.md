## DeepSeek Harness 桌面版：能不能改造

Tim 问官方桌面版装完能不能改造（因为开源）。

查证结论：
- 内核 `github.com/deepseek-ai/deepseek-harness`，**MIT**，TypeScript 全源码
- 桌面版是 Electron 壳，包同一套 Web UI；官网给的是安装包（编译产物），要改必须拿源码 build
- **换皮不用碰源码**：官方就是「一切皆插件」（Cordis 微内核），主题走
  `ctx.theme.overrideTokens()` 覆盖 `--dsw-alias-*` 令牌 + `settings.general.item` 插槽加设置项
- 社区已有一堆皮肤插件（dsh-skin、dsh-ui-appearance 等），全是纯 client 插件，卸载即恢复
- 坑：靠 class 哈希命中的控件联动，DSH 升级后会静默失效；只覆盖 token 才安全

Tim 的方向定了：**先换皮 / 改界面，之后再慢慢自己造插件。**
我提议把 Rezig 的「高山冷光」设计系统转成一套 `--dsw-alias-*` 令牌，做成他的第一个皮肤插件 —— 待他拍板。

## GitHub 直连不通 → 查清是 CLI 没接系统代理

换皮讨论中我提了一句「这台机器直连 GitHub 不通」，Tim 让我先解决。

诊断（全部只读）：
- DNS 正常（`20.205.243.166`）、`/etc/hosts` 干净、`scutil --proxy` 显示系统代理**已开**
  （HTTP/HTTPS/SOCKS 全指向 1097，`ZionLadder` 在监听）
- 直连 `github.com:443` → TCP 超时；经 1097 → HTTP/2 200

**根因：macOS 系统代理只有 GUI 应用读，curl/git/npm/brew 只认环境变量。**
ZionLadder 只设了系统代理，`~/.zshrc` 里一条代理变量都没有 → 终端全程裸奔直连。

修复（Tim 选的方案）：`~/.zshrc` 追加带**探活**的代理块，备份在 `~/.zshrc.bak-20261001`。
探活是为了避开 Tim'Radio 那个同源坑（代理写死全局 env，ZionLadder 一没开就全线瘫痪）。

验证：新 shell 下 `http_code=200`，`git ls-remote` 官方 harness 仓库拿到 HEAD `639ed01`。
