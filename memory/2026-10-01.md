## DeepSeek Harness 桌面版：能不能改造

Tim 问官方桌面版装完能不能改造（因为开源）。

查证结论：
- 内核 `github.com/deepseek-ai/deepseek-harness`，**MIT**，TypeScript 全源码
- 桌面版是 Electron 壳，包同一套 Web UI；官网给的是安装包（编译产物），要改必须拿源码 build
- **换皮不用碰源码**：官方就是「一切皆插件」（Cordis 微内核），主题走
  `ctx.theme.overrideTokens()` 覆盖 `--dsw-alias-*` 令牌 + `settings.general.item` 插槽加设置项
- 社区已有一堆皮肤插件（dsh-skin、dsh-ui-appearance 等），全是纯 client 插件，卸载即恢复
- 坑：靠 class 哈希命中的控件联动，DSH 升级后会静默失效；只覆盖 token 才安全

Tim 的方向定了：**先换皮 / 改界面，之后再慢慢自己造插件。**
我提议把 Rezig 的「高山冷光」设计系统转成一套 `--dsw-alias-*` 令牌，做成他的第一个皮肤插件 —— 待他拍板。

## GitHub 直连不通 → 查清是 CLI 没接系统代理

换皮讨论中我提了一句「这台机器直连 GitHub 不通」，Tim 让我先解决。

诊断（全部只读）：
- DNS 正常（`20.205.243.166`）、`/etc/hosts` 干净、`scutil --proxy` 显示系统代理**已开**
  （HTTP/HTTPS/SOCKS 全指向 1097，`ZionLadder` 在监听）
- 直连 `github.com:443` → TCP 超时；经 1097 → HTTP/2 200

**根因：macOS 系统代理只有 GUI 应用读，curl/git/npm/brew 只认环境变量。**
ZionLadder 只设了系统代理，`~/.zshrc` 里一条代理变量都没有 → 终端全程裸奔直连。

修复（Tim 选的方案）：`~/.zshrc` 追加带**探活**的代理块，备份在 `~/.zshrc.bak-20261001`。
探活是为了避开 Tim'Radio 那个同源坑（代理写死全局 env，ZionLadder 一没开就全线瘫痪）。

验证：新 shell 下 `http_code=200`，`git ls-remote` 官方 harness 仓库拿到 HEAD `639ed01`。

**LICENSE 结论（之前的问号解了）**
- 根 `LICENSE` = **MIT, (c) 2026 DeepSeek**，覆盖整个 monorepo
- `apps/desktop/package.json` → `"license": "MIT"`，**没有独立 LICENSE**
- → **官方桌面壳（Electron）确实开源**，就在 `apps/desktop/`

**桌面壳是怎么回事**
- Electron 壳包**完整的 dsh Web 应用**，走 `dsh-app://app/` 加载打包好的 Web 入口
- 桌面默认端口 **19387**（Web 版是 3080）
- `main: lib/main.js`；`renderer/`（升级弹窗等）/ `src/`（主进程）/ `installer/` / `resources/`
- 构建：`pnpm run dev:desktop`（开发跑）；`pnpm run package:desktop:mac:arm64:dir`（出未签名可运行目录）
- ⚠️ 正式打 macOS 包要 **Apple Developer ID 证书 + 公证**（Tim 多半没有）→ 自用只能走 `:dir`

**皮肤插件 API（干货，全在 `packages/client/ui-theme/src/client/index.ts`）**
- 服务 `ctx.theme`（ThemeRuntime），入口：
  - `overrideTokens(source, tokens)` —— 叠加覆盖层，返回 disposer（**换皮主要用这个**）
  - `register({ id, colorScheme, tokens })` —— 注册整套新主题
  - `setTheme(id)` / `getTheme()` / `exportInspectTokens()`；事件 `theme/change`
- **14 个可覆盖 token**（全部强制 `{ light, dark }` 双值，传裸字符串会抛教学式错误）：
  `bg-base` / `bg-layer-1` / `bg-layer-2` / `bg-overlay` / `border-l1` / `border-l2` /
  `brand-primary` / `label-primary` / `label-secondary` /
  `state-error-primary` / `state-idle-primary` / `state-success-primary` / `state-warn-primary` /
  `specific-sidebar-fill`（侧栏与标题行）。另有 `--dsw-font-family` 可覆盖
- 设置项入口插槽：`settings.general.item`
- 仓库自带官方插件开发指南：`packages/preset/agent-preset/skills/cordis-plugin-development/`
