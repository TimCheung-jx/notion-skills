- 报错：`Invalid schema for function 'codex_app::automation_update': schema must be a JSON Schema of 'type: "object"', got 'type: null'`。
- 定性：Codex 桌面版（ChatGPT.app 内置，build 26.908.40834，约 9/8 自动更新——与「突然坏」时间吻合）每次请求把内置工具表连同 JSON Schema 发给模型接口；`automation_update`（桌面版自动化功能工具）的 schema 里有 `type: null`，不合法。DeepSeek Responses API（`~/.codex/config.toml` 里 model_provider=deepseek）严格校验，整条请求 400 拒收 → 每轮对话必炸。
- 属 Codex 已知问题类别（openai/codex#4859 同类：automation_update schema 无效 + 报错信息失真）；官方端点组合多数人未炸，DeepSeek 校验更严才暴露。
