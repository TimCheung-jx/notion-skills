## Codex 突然不可用诊断

- 报错：`Invalid schema for function 'codex_app::automation_update': schema must be a JSON Schema of 'type: "object"', got 'type: null'`。
- 定性：Codex 桌面版（ChatGPT.app 内置，build 26.908.40834，约 9/8 自动更新——与「突然坏」时间吻合）每次请求把内置工具表连同 JSON Schema 发给模型接口；`automation_update`（桌面版自动化功能工具）的 schema 里有 `type: null`，不合法。DeepSeek Responses API（`~/.codex/config.toml` 里 model_provider=deepseek）严格校验，整条请求 400 拒收 → 每轮对话必炸。
- 属 Codex 已知问题类别（openai/codex#4859 同类：automation_update schema 无效 + 报错信息失真）；官方端点组合多数人未炸，DeepSeek 校验更严才暴露。
- 规避选项：① 升级 Codex 等修复；② 关 `codex-app-tools@openai-bundled` 插件让该工具不再随请求发送（代价：桌面版自动化/应用集成不可用）；③ 向 DeepSeek 反馈校验过严。

## Rezig AI 产品：命名 + 设计系统（晚间 20:41–22:35）

起点是个闲聊问题「仙乃日是不是菩萨的意思」，一路滚成产品命名和整套 UI 方案。

**藏语/佛教知识（已核实）**
- 稻城亚丁「三怙主」：仙乃日 6032m = 观音菩萨；央迈勇 5958m = 文殊；夏诺多吉 5958m = 金刚手
- Chenrezig = 藏文 སྤྱན་རས་གཟིགས་ / Wylie `spyan ras gzigs`。是**意译不是音译**，
  跟梵文 Avalokiteśvara 读音无关：spyan=眼，gzigs=看。所以中文抓听觉（观世音=音）、
  藏语抓视觉（眼）——这条分轴成了后面命名的支点
- 罗马化变体：Chenrezig / Chenrezi / Chenresig / Chenrezik / Chenrézik；藏汉佛典译作「坚热斯」
- 发音 /tʃenˈreɪzɪɡ/ 重音在中间；拉萨话实际更接近 chen-RE-zi，尾 g 是喉塞

**命名结论**：英文名定为 **Rezig**；中文市场另起炉灶，首选 **察音**，备选 **观智**。
完整候选表与判决理由见 `memory/topics/rezig.md`。
