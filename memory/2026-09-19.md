# 2026-09-19

## 法律问答：挪用资金罪立案追诉标准

Tim 问「根据最新规定，挪用资金罪的立案追诉标准是多少钱」（13:22 本地）。

**结论（立案追诉门槛，问的就是这个）**

| 情形 | 立案数额 |
|---|---|
| 进行非法活动 | 3 万元以上 |
| 进行营利活动 | 5 万元以上 |
| 超过三个月未还 | 5 万元以上 |

依据《最高检、公安部关于公安机关管辖的刑事案件立案追诉标准的规定（二）》第 77 条，
2022-04-29 发布、2022-05-15 施行，同时废止 2010 年公通字〔2010〕23 号。
这一版把挪用资金罪的入罪标准拉平到与挪用公款罪同级，体现产权平等保护，
因此不再适用过去「按挪用公款罪 2 倍」的算法。

**新变化**：法释〔2026〕6 号《关于办理贪污贿赂刑事案件适用法律若干问题的解释（二）》
（2026-04-10 发布，2026-05-01 施行）第八条，把挪用资金罪的**定罪量刑标准**改为
「分别参照挪用公款罪定罪量刑标准执行」。动的是**量刑档次**，不是立案门槛——
上面三个数字仍然有效。

**故意没给的部分**：数额巨大 / 数额特别巨大的具体金额。
- 已核官方全文（山西高院转载版）：解释（二）正文只写「参照」，
  挪用资金、挪用公款两处**均未直接规定数额**
- 第三方文章数字互相打架（400 万 / 100 万 / 200 万），其中一篇把「特别巨大」写得
  低于「巨大」，逻辑上不成立 → 拒绝给出
- 已向 Tim 说明，建议等两高配套《理解与适用》或个案请示

**行为时法提示**：2026-05-01 前后发生的行为分别适用新旧标准，跨期案件不能一把尺子量到底。
