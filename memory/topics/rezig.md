## 名称由来

Rezig ← Chenrezig ← 藏文 སྤྱན་རས་གཟིགས་（Wylie: `spyan ras gzigs`），藏语对观音菩萨的称呼。
罗马化变体还有 Chenrezi / Chenresig / Chenrezik / Chenrézik；藏汉佛典译作「坚热斯」。
发音 /tʃenˈreɪzɪɡ/，重音在中间；拉萨话实际更接近 chen-RE-zi，尾 g 是喉塞——
所以砍掉尾音 g 的 Rezi 系列其实更贴真实发音，英文那个 g 是拼写残留。

**关键事实**：藏语是**意译不是音译**。spyan=眼，gzigs=看，意为「以眼注视者」，
跟梵文 Avalokiteśvara 在读音上毫无关系。
中文抓听觉（观世音=音），藏语抓视觉（眼）——**这组分轴是命名叙事的支点**：
察音是听觉，Rezig 是视觉，同源分家，可做双线叙事。

**品牌句（定稿）**：
> Rezig 取自 Chenrezig——藏语里的观音菩萨，四川仙乃日神山即其化身，字面意为"慈悲注视之眼"。

（初稿里 Tim 写了「大概是」，已建议去掉：品牌文案里 hedge 泄气；「字面意为」本身已留余地，
法律和调性两头都稳。）

## 候选名与判决

| 名字 | 定位 | 结论 |
|---|---|---|
| **Rezig** | 英文/国际 | **采用**。砍头留尾，比 Chenrezig 好念且更贴藏语实际发音 |
| Chenrezi | 英文备选 | 藏语标准异拼，零发明，完整保留宗教指向 |
| **察音** | 中文首选 | 生造搭配 → 显著性最强、注册阻力最小、完全避开「观音」音形。偏冷 |
| 观智 | 中文备选 | 传播更好，显著性中等 |
| 睿泽 | 中文备选 | 从 Rezai 倒推，稳妥但「睿」字在科技公司里过挤 |
| 瑞兹 | — | **毙**：撞英雄联盟 Ryze，中文用户必联想 |
| 知音 | — | **毙**：通用词，显著性弱，撑不起强商标 |
| 观自在 | — | **毙（主营）**：宗教指向明确，9/42 类「不良影响」驳回概率高。可留作功能线名 |

**选择判据**：产品做声音/语音 → 察音；更宽泛的智能产品 → 观智。

中间还试过 Rezai（Rezi + AI，名字里直接躺着 AI 两个字母），作为音译来源保留。

## 设计系统

风格代号「高山冷光 / Alpine Cold Light」，暗色优先。
参考图是 Tim 给的一张企业培训海报（深蓝底 + 青强调 + 同心弧 + 全零暖色）。
没有直接用，而是先给配色找了「非它不可」的理由：
深蓝=高原夜空、青=冰川裂隙的光、同心弧=感知半径。

对原图动了五处：
1. 补暖色（朱砂 + 日出金，面积压到 2%）——原图零暖色，UI 里无法表达错误/警告态
2. 标题改思源宋体，拆掉通用 SaaS 观感
3. 圆形收归同心弧专属，按钮不用 pill（太消费级，也稀释了圆形的专属性）
4. 同心弧从背景装饰升级成**品牌母题 + AI「思考中」动效**（弧向外扩散淡出，2.4s；禁止做成转圈 spinner）
5. 文字不用纯白，改 #F2F6FA（暗底上纯白会晕）

文档含：四组色板各七阶、语义 token、字阶、间距节奏（8pt，区块间跳跃到 64/96）、
圆角、组件参数、动效曲线、对比度实测、亮色模式映射。
